# IMS
Данный проект реализуется для дипломной работы. 
Основная цель — практика и решение поставленной задачи в ходе прохождения преддипломной практики и научно-исследовательской работы.

Цель проекта — создать систему управления запасами, позволяющую вести контроль и учет материальных ценностей участка воздушных линий.
