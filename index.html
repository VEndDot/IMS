Зачем создан проект?

IMS решает задачу автоматизации складского учета для бригад, обслуживающих воздушные линии электропередач. Приложение позволяет вести иерархический справочник материалов, фиксировать факт списания с автоматическим пересчетом остатков и формировать историю операций для отчетности.

  • Защита от отрицательных остатков и транзакционное списание
  • Ролевая модель: Администратор / Мастер участка
  • Поиск по всей цепочке: Категория → Подкатегория → Тип → Номенклатура

Ключевые возможности

Иерархический каталог

4 уровня классификации: Категории, Подкатегории, Типы и Номенклатура с артикулами, ГОСТ и сечением.

Учет списаний

Создание заявок на списание, валидация остатков, атомарное уменьшение стока через транзакции EF Core.

Безопасность и роли

Cookie-аутентификация, хеширование паролей (SHA-256), ограничение доступа по ролям `admin` и `user`.

Технологический стек

.NET 8+ Blazor Server (Interactive) Entity Framework Core SQL Server Clean Architecture Bootstrap 5 Cookie Auth

Архитектура решения
